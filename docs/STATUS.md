## 复现入口

```powershell
# 只检查题源。
python -m moumou --plan

# 真实老师会话、模型调用与实际人类交互。
python -m moumou

# 框架回归，与老师任务质量分开。
python -m pytest -q

# 读取已有结果，不重新运行任务。
python -m moumou.eval.report --run runs/test/EXISTING_SESSION
```

`make test` / `make eval` 使用正式任务协议，`make unit-test` 使用 pytest。默认题库为 `eval/tasks`；保留的十五题补充库须显式指定 `--tasks eval/supplementary`，并使用单独分母。
