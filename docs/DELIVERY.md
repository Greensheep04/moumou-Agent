## 评测候选版本前

1. 记录目标 commit、源码/dirty 状态、环境和选择题源。按环境说明激活原生 Windows Conda 环境；仅通过解释器绝对路径启动不会激活子进程 `PATH`。
2. 执行适用的框架检查，保留命令、输出、退出码、耗时和平台跳过。清单本身不表示检查已经执行。
3. 只配置课程允许的 DeepSeek/HKGAI 服务。真实密钥保存在忽略的 `.env`，无密钥模板见 [`.env.example`](../.env.example)。
4. 通过统一入口和新输出目录运行老师题源，保留每组四角色及组内任务连续状态。
5. 记录实际人类答复/权限，独立检查交付。工具许可、子测试全绿或 Agent `DONE` 都不是最终质量验收。
6. 保留所有计划目标，包括失败、未发布和未知质量。修复版本使用独立证据，不能清除旧失败。

每组初始六次新的 Tavily 请求由四角色和两题共享，完整老师三组初始共十八次；缓存另计。增加额度需明确且有记录的授权。该限制不限制学校模型推理/token 访问额度。

## 每次运行保留的证据

| 证据 | 必需含义 |
| --- | --- |
| `test.json` 和原题源哈希 | 固定计划、执行身份、配置及实际保存状态 |
| 每阶段 `task_N-result.json` | 根/子任务状态、交付时间、usage 观测和原质量 |
| `dialogue.jsonl`、trace 和人类记录 | 实际发送的模型输入、执行事件及原请求/答复身份 |
| 产物清单与副本 | 交付文件字节、路径、捕获时间/完整哈希及部分/排除状态 |
| 记忆/失败快照 | 保存阶段的元数据和观测，保留未知覆盖 |
| 场景关闭诊断 | 已观测到的未完成状态，不新增交付或分母 |
| 离线复核记录 | 明确质量决定、题源/结果绑定和替代审阅链 |
| 派生报告/分析/回放 | 构建者身份与原执行身份分开，原证据不变 |

强制停止可能留下原始 `running` 状态，应同时保留该文件和实际外部停止证据，不能伪造正常收尾。不能读取后续可变工作区或实时记忆数据库，称其为早期交付。文件副本是选定字节捕获，不保证正在使用的数据库达到事务一致性备份。

## Git 中保留什么

提交实现、有意义的回归源码、原题输入、环境模板和维护的公开 Markdown 文档。保留完整真实提交历史，不修改作者归属，不制造每日开发活动。

老师没有把单独提交 `tests/` 列为硬性材料。建议将有意义的回归源码随完整代码保留，便于复现和维护；
其通过数量不是老师题库成绩。缓存、临时文件和本地测试输出不需要上传。

本地规划和交接笔记、私有证据归档、`.env`、密钥、运行数据库、原始 `runs/` 和缓存保持忽略。真实证据产生后再提供经审阅脱敏的性能报告和选定最终截图。文档使用 Markdown 或纯文本；提交历史截图必须是真实仓库历史的实际截图，不能生成或重绘代替。

经批准的最终交付提交形成后，再捕获包括各成员真实贡献的最终历史。可用于定位历史的只读命令：

```powershell
git log --graph --decorate --oneline --all
git log --all --format="%h %ad %an %s" --date=short
git shortlog -sne --all
```

最终候选的截图与贡献证据仍待补。作者别名应与真实成员核对；仅凭 commit 数量不能证明贡献的重要程度。

## 文档组织与历史保留

使用[中文 README](../README.md)导航，当前命令以环境、评测和接口页为准。P1 执行、交接、演示和外部服务说明仍保留作技术参考；带日期的结果只适用于其声明版本。当前正式评测使用 `python -m moumou` 及同一 CLI 协议。

十四份带日期的执行计划、进度和中间验收记录已从当前文档目录清理。原内容仍可在[已发布 e35e820 文档树](https://github.com/Greensheep04/moumou-Agent/tree/e35e8204a3ff2d1b798e1b055bd3cc9706f0a6e9/docs)及 Git 历史查找，本地备份不进入交付。清理过期导航不否定或替换原历史测量。

拟交付目录不含 GitHub Actions 工作流，检查通过明确命令运行。本地删除文件不会删除托管历史，也不会在批准的删除到达远端前改变其他分支。不能把未执行的检查或历史 CI 宣传为最终候选通过。

## 仍待完成的验收

- 执行候选版本回归、lint 及相关 Windows 恢复/并发检查。
- 运行并审阅老师六目标，保留失败和未知结果。
- 按实际协商标准检查生成的 CLI/网页/数据库交付。
- 记录真实 P0/P1/P2 对接验收和记忆观测，不夸大因果收益。
- 补齐性能报告、真实贡献截图与演示证据。
- Final 闭集发布后单独评测，不能把 mid-term 或补充题结果改称未见过的 Final Set 结果。
